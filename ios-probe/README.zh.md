## build 3 修正与验证历史

- 清除命令发送成功后进入“等待确认真实位置”，保留恢复标记；核对真实位置并确认后才能开始下一轮。不会仅依据发送成功就解除恢复提示。
- 清除后等待停止请求传输，再释放定位连接；旧通道失败时继续保留重连重试。
- 活跃会话持有 `CLBackgroundActivitySession`，启用持续定位反馈；结束时停止反馈并释放会话。参见 [Apple 后台定位说明](https://developer.apple.com/documentation/corelocation/handling-location-updates-in-the-background)。
- 地图蓝点展示系统位置；橙色标记只代表发送目标。界面增加系统位置来源反馈，避免把目标动画等同于实际位置更新。
- 运行记录增加前后台切换、速度、目标推进距离、系统模拟位移；最近两次应用运行记录保存在本机私有目录。真实经纬度、配对文件和账号资料不进入日志。

已观察到系统定位服务收到多次模拟位移，build 3 在后台也持续收到 Core Location 返回的模拟位置变化。苹果地图可以持续移动；2026-11-04 用户确认百度地图 22.1.20 在同一条上海路线下也持续移动。同机的高德 17.02.2 首页和步行导航仍不持续移动。将完全相同的上海 76 点路线交给 StikDebug 3.2.0 播放，高德也未持续移动，但这次参考工具播放期间的系统位移未独立采集。现有对照不能确定具体原因，也不能证明其他应用全部兼容。2026-11-04 的一次恢复通过电脑独立清除，再关闭并重开高德后由用户确认；不能将其记为应用自行停止恢复已通过。

## 本版本功能

- Apple 地图显示、缩放、卫星样式、当前位置、全路线预览。
- 搜索地点或输入经纬度；长按地图选点、拖动标记调整位置。
- 起点、终点、最多 6 个途经点，支持删除和调整顺序。
- 步行、驾车、骑行道路规划；骑行入口仅在 iOS 27 及以上显示。道路服务没有结果时提示失败，不替换成直线。
- 独立的“直线”方式，可不请求道路服务，沿选点顺序连接。
- 路线距离和模拟时长预览、收藏至本机、再次载入、删除收藏。
- 导入 GPX/XML/双列坐标文本，最多 5 MB / 50,000 点；导入后可预览和收藏。
- 单程、循环、往返；运行中调速、暂停和继续；停止时清除模拟位置。
- 默认不限时，可选定时结束。本 App 在前台运行时保持屏幕常亮。

地图、搜索与道路规划依赖 Apple 在线服务及其区域覆盖，选点和查询会发送至该服务。收藏和配对资料存放于本机私有目录；更新同一应用时保留，卸载会删除。本版尚未移植安卓 BRouter 离线路网和完整路线配置，不等于安卓所有功能已完成。

## 定位连接与首次设置

1. 保留开发者模式，并完成开发者映像初始化。手机重启后若服务未就绪，仍需通过已验证的电脑工具或 StikDebug 初始化，本版尚未自动挂载开发者映像。
2. 在设置页点“打开并连接 LocalDevVPN”，由用户确认必要的系统提示。沿用已验证的 Wi-Fi 条件。
3. 首次导入这台手机的配对文件，可从“我的 iPhone → StikDebug → pairingFile.plist”选择。文件验证后存入应用私有目录，不放进安装包、收藏或日志。
4. 点“连接本机”。默认端口 49152，可在高级设置查找 Bonjour 服务或手填端口。连接地址固定为本机 VPN 地址 10.7.0.1。
5. 初次设置完成后，日常使用本 App 和 LocalDevVPN，无需每次打开 StikDebug。VPN 尚未内置，不能宣称已经实现单 App 独立配置。

保留基础包标识 `net.routeforge.locationprobe`，更新时继续使用原签名账号，以保留配对资料。桌面名称改为“轨迹导航”。
