# RouteForge 苹果端

0.2.0 将界面从定位通道测试页改为地图、路线和设置三个页面。当前源码已完成本地语法和配置检查，**尚未通过本版本的 Xcode 编译或真机功能验收，不能将新功能记为实测通过**。

## 本版本功能

- Apple 地图显示、缩放、卫星样式、当前位置、全路线预览。
- 搜索地点或输入经纬度；长按地图选点、拖动标记调整位置。
- 起点、终点、最多 6 个途经点，支持删除和调整顺序。
- 步行、驾车、骑行道路规划；骑行入口仅在 iOS 27 及以上显示。道路服务没有结果时提示失败，不替换成直线。
- 独立的“直线”方式，可不请求道路服务，沿选点顺序连接。
- 路线距离和模拟时长预览、收藏至本机、再次载入、删除收藏。
- 导入 GPX/XML/双列坐标文本，最多 5 MB / 50,000 点；导入后可预览和收藏。
- 单程、循环、往返；运行中调速、暂停和继续；停止时清除模拟位置。
- 默认不限时，可选定时结束。本 App 在前台运行时保持屏幕常亮。

地图、搜索与道路规划依赖 Apple 在线服务及其区域覆盖，选点和查询会发送至该服务。收藏和配对资料存放于本机私有目录；更新同一应用时保留，卸载会删除。本版尚未移植安卓 BRouter 离线路网和完整路线配置，不等于安卓所有功能已完成。

## 定位连接与首次设置

1. 保留开发者模式，并完成开发者映像初始化。手机重启后若服务未就绪，仍需通过已验证的电脑工具或 StikDebug 初始化，本版尚未自动挂载开发者映像。
2. 在设置页点“打开并连接 LocalDevVPN”，由用户确认必要的系统提示。沿用已验证的 Wi-Fi 条件。
3. 首次导入这台手机的配对文件，可从“我的 iPhone → StikDebug → pairingFile.plist”选择。文件验证后存入应用私有目录，不放进安装包、收藏或日志。
4. 点“连接本机”。默认端口 49152，可在高级设置查找 Bonjour 服务或手填端口。连接地址固定为本机 VPN 地址 10.7.0.1。
5. 初次设置完成后，日常使用本 App 和 LocalDevVPN，无需每次打开 StikDebug。VPN 尚未内置，不能宣称已经实现单 App 独立配置。

保留基础包标识 `net.routeforge.locationprobe`，更新时继续使用原签名账号，以保留配对资料。桌面名称改为“轨迹导航”。

## 编译与签名

需要 macOS、Xcode 27、Python 3.11+ 与 XcodeGen。执行 `bash scripts/build.sh`：校验固定依赖、执行 RouteCore 测试、生成 Xcode 工程、编译，再输出 `build/RouteForgeProbe-unsigned.ipa`。IPA 需在 Windows 使用现有 iloader 账号签名安装，云端不接收 Apple ID 资料和手机配对文件。

GitHub Actions 仅手动触发，产物保留 3 天。遵循项目 AGENTS.md：允许本地编译、测试、签名和更新手机；只有用户明确要求上传或发布时才推送 GitHub，不能每次修改后自动上传。

本地检查覆盖 Swift/C 语法、YAML/plist、构建脚本和 13 个原生函数的符号匹配，不能代替 Xcode 类型检查和链接。新增 6 项核心测试覆盖点位编辑、途经点上限、坐标格式、收藏编码、暂停不追赶、循环与往返；需随下一次 macOS 构建执行。

## 验证记录与下一轮验收

0.1.0 已在 macOS 编译并通过原 7 项核心测试，在 iPhone 15 Pro / iOS 27.0.1 安装。用户确认拔线定点、手动停止恢复、高德前台持续绕圈 10 分钟并自动恢复真实位置通过。这只证明旧版定位底层，不证明 0.2.0 的地图和规划功能。

0.2.0 安装后依次验证：

1. 更新后保留配对资料；地图能显示本地区街道，当前位置与高德对应。
2. 搜索本地区地点，设置起终点和途经点；按服务覆盖生成步行/骑行/驾车道路折线，失败有明确提示。
3. 拖动点位、调整顺序后重新生成；收藏后关闭再打开，仍可载入。
4. 拔线播放，确认移动；暂停保持位置、继续不跳过暂停时间，运行中调速正常。
5. 停止、单程到终点、定时结束均尝试清除模拟位置，在高德核对真实定位。

清除命令成功后可继续使用；若失败或上次运行异常退出，则保留恢复入口，不直接开始下一段模拟。其他地图可能缓存位置，仍以手机观察为准。锁屏、30 分钟按用户要求不列入当前验收。本 App 不能替高德控制屏幕常亮。
